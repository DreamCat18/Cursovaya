Рус-корректор
Интеллектуальная система обнаружения и исправления ошибок в русскоязычных текстах иноязычных авторов

Курсовой проект по МДК.04.03 «Сопровождение интеллектуальных систем»
Специальность 09.02.07 «Информационные системы и программирование»

1. Назначение и область применения
1.1. Наименование программы: «Рус-корректор» (далее — Система).

1.2. Назначение: Система предназначена для автоматического обнаружения и исправления грамматических, орфографических и пунктуационных ошибок в текстах на русском языке, написанных иностранцами.

1.3. Область применения: Проверка учебных работ, деловой переписки, статей и любых текстов, созданных авторами, для которых русский язык не является родным.

1.4. Основные функции:

Проверка текста на наличие ошибок с использованием специализированных моделей (SAGE, Qwen2.5).

Подсветка ошибочных фрагментов прямо в тексте.

Предоставление списка ошибок с объяснениями.

Предоставление чистого исправленного текста (для копирования).

Консультация в чате по правилам русской грамматики.

2. Руководство оператора (в соответствии с ГОСТ 19.505-79)
2.1. Условия выполнения программы
Для работы Системы необходим компьютер с:

Операционной системой Windows (или Linux/WSL).

Браузером (Chrome, Edge, Firefox и т.д.).

Установленным Python 3.11+.

Установленной программой Ollama (для работы нейросети).

Свободным портом 8000.

2.2. Порядок запуска программы
Убедитесь, что запущена служба Ollama (ollama serve).

Откройте терминал в папке проекта.

Активируйте виртуальное окружение:
source .venv/Scripts/activate (Windows) или source .venv/bin/activate (Linux/WSL).

Запустите сервер:
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000

Откройте браузер и перейдите по адресу: http://127.0.0.1:8000

2.3. Работа с программой
Ввод текста. Вставьте или напишите текст в левое поле «Ваш текст».

Запуск проверки. Нажмите кнопку «Проверить». Дождитесь ответа (обычно 5–15 секунд).

Анализ результатов. Ошибки будут выделены цветом (красный — грамматика, зелёный — пунктуация). В правой панели появится список ошибок с объяснениями.

Навигация. Клик по ошибке в списке прокручивает текст к нужному месту.

Копирование. Перейдите на вкладку «Исправленный текст» и нажмите «Скопировать чистовик».

Чат. Перейдите во вкладку «Чат», напишите вопрос о правиле (например: «Почему пишется "в общем"?») и нажмите «Отправить».

2.4. Сообщения оператору
«Ошибок не найдено» — текст проверен, ошибок не обнаружено.

«Проверяем текст…» — идет обработка, подождите.

«Ошибка проверки» — возможно, модель Ollama не запущена или сервер недоступен. Проверьте терминал.

2.5. Завершение работы
Закройте браузер. В терминале нажмите Ctrl+C, чтобы остановить сервер.

3. Установка и настройка (для администратора)
3.1. Требования
Python 3.11

Ollama (с установленной моделью qwen2.5:7b-instruct)

PostgreSQL (опционально, для истории проверок)

3.2. Порядок установки
Клонируйте репозиторий или распакуйте архив проекта.

Создайте виртуальное окружение:
python -m venv .venv

Активируйте окружение:
source .venv/Scripts/activate

Установите зависимости:
pip install -r requirements.txt

Установите модель Ollama (если еще не установлена):
ollama pull qwen2.5:7b-instruct

3.3. Настройка
Скопируйте .env.example в .env.

Отредактируйте .env, указав адрес Ollama, имя модели и параметры PostgreSQL.

Краткое описание модулей:

app/api/check.py — обработка запроса на проверку текста. Содержит резервные правила, вызов SAGE и LLM, сравнение текстов через difflib и сохранение истории в БД.

app/services/ollama.py — клиент для работы с локальной моделью Qwen2.5 через Ollama.

app/services/spell_corrector.py — клиент для работы с моделью SAGE (исправление орфографии).

app/db.py — настройка SQLAlchemy и функция сохранения истории проверок в PostgreSQL.

app/static/js/app.js — клиентская логика: отправка запросов, подсветка ошибок, работа с вкладками.
