Как работает проверка

Система обнаруживает семь типов ошибок, характерных для иноязычных авторов:

  • Падежное управление — «ехал в Москва» → «ехал в Москву»
  • Согласование — «новый школу» → «новую школу»
  • Вид глагола — «читал весь день» → «прочитал за день»
  • Порядок слов — «очень мне нравится» → «мне очень нравится»
  • Лексическая сочетаемость — «сделать решение» → «принять решение»
  • Предлоги — «говорю на русский язык» → «говорю по-русски»
  • Пунктуация — «думаю что» → «думаю, что»

Модель работает локально: текст не отправляется на сторонние серверы.
